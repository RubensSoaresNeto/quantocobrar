# Quanto Cobrar?

Aplicativo Flutter para prestadores de serviços calcularem e compartilharem
orçamentos profissionais.

## Funcionalidades

- Cálculo de materiais, mão de obra, despesas, acréscimo e desconto.
- Dados do cliente e validade do orçamento.
- Histórico local dos últimos orçamentos.
- Perfil profissional com telefone e chave Pix.
- Compartilhamento, cópia do texto e geração de PDF.
- Temas claro, escuro e automático.
- Funcionamento offline, sem login e sem servidor.

## Executar

```bash
flutter pub get
flutter run
```

Para executar no navegador:

```bash
flutter run -d chrome
```
